# Prism Helper releases

Signed builds of **Prism Helper**, the small app that syncs an Unlearn Health Prism to your Unlearn account.

- Installed Helpers update themselves from this repository's latest release (`latest.json`), and every update is signature-checked.
- New Mac users: download the latest release's `Prism Helper for Mac.zip` and follow its README.
- Source code is private. Only release files are published here.
